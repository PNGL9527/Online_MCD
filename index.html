    About the diagram & exploratory additions

    From the paper: relation type is encoded by shape, relative impact by marker size, transparency by opacity, and forefronting by position in the field (§3.2.4). The driving examples follow the qualitative descriptions in §3.3. The diffuse yellow region depicts a field-compositional influence; it is not an additional mediation unit or a measured area.

    Exploratory addition: sedimentation replaces the opacity channel with color while preserving size and position. Transparency and sedimentation are stored independently. Sedimentation concerns habit strength associated with long-term bodily-perceptual practices; it cannot simply be inferred from transparency, frequency, or duration of use. Gray, dashed markers mean sedimentation has not been assessed.

    Illustrative values: the paper does not supply numerical scores or sedimentation ratings. Example positions and slider values are illustrative encodings. Example sedimentation values remain the same across A and B; changing driving conditions is not assumed to immediately change habits. New projects begin by defining mediation granularity and then start with an empty field, with no preassigned sedimentation ratings.

    Analysis: define the analytical purpose and cut before adding relations. The project records the description and optional rationale; the app does not automatically assess the appropriateness of the cut. Name units according to the selected analytical cut, rather than assuming every artifact is one unit. A unit's relation type is editable and contingent on the situation. Selective grouping or differentiation can be explored by editing, adding, or removing units; the app does not impose a technical hierarchy.

    Scope: each project represents one situated configuration. Duplicating it supports comparison; neither a snapshot nor a color encoding explains the temporal formation of sedimentation. Diffuse-region controls are experimental drawing conventions. Geometry and slider values are qualitative, not measurement scales.

    Saving: automatic saving is confined to this browser and this page address when storage is available. Download a project JSON for a portable backup, sharing, or moving from the local HTML to a hosted site. SVG and PNG exports are visual snapshots; import the JSON to continue editing. Imported files create a separate project.
